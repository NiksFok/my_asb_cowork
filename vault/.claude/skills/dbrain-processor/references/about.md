## Anti-Patterns (AVOID)

When processing entries DO NOT:
- Создавать абстрактные заметки без action items
- Делать задачи расплывчатыми типа «подумать о...»
- Дублировать контент без синтеза
- Создавать списки без приоритетов
- Игнорировать связь задач с ИИзацией и карьерными целями
