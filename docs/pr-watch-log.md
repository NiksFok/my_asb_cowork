# Журнал наблюдения за внешними pull request'ами

Служебный файл ежедневной routine-проверки входящих PR в `NiksFok/my_asb_cowork`.
Нужен, чтобы уведомления уходили только по НОВЫМ или ИЗМЕНИВШИМСЯ PR, а не
повторялись каждый день по одному и тому же висящему реквесту.

Правило: если `head sha` и `updated_at` у открытого PR совпадают с записью ниже
и решение владельца ещё не принято — повторное уведомление не отправляется.
Любое изменение (новый пуш, ревью, комментарий, новый PR) снова считается
поводом написать.

| PR | Автор / форк | Заголовок | head sha | updated_at | Уведомление отправлено | Решение владельца |
|----|--------------|-----------|----------|------------|------------------------|-------------------|
| [#1](https://github.com/NiksFok/my_asb_cowork/pull/1) | Deniz-h-art / `Deniz-h-art/my_asb_cowork-1` | 🎓 Учебный режим: личный репетитор в отдельной сессии | `35403c5` | 2026-07-13T20:37:57Z | 2026-10-09 | ⏳ ожидает |

## Замечания по PR #1 (на случай решения «мержить»)

Разбор от 2026-10-09, `+471/−8`, 16 файлов, `mergeable_state: clean`, CI в репозитории нет.

1. `STUDY_MODEL` по умолчанию `claude-sonnet-5` (`.env.example`, `config.py`) —
   проверить валидность ID модели перед вливанием, иначе учебная сессия не поднимется.
2. У учебной сессии нет аналога `_ask_lock` из `services/runtime.py`: два быстрых
   сообщения подряд могут наложиться в одной tmux-панели.
3. Путь к персоне в `get_study_session` считается как
   `vault_path.parent / "deploy" / "study-system.md"` — упадёт с `RuntimeError`,
   если `VAULT_PATH` вынесен за пределы проекта.
4. Косметика: собственный `_EXIT_TRIGGERS` в `handlers/study.py` недостижим после
   появления глобального `buttons.exit_router`; текст выхода из `/do` меняется
   с «✅ Диалог завершён.» на «✅ Завершено. Возврат в главное меню.».
